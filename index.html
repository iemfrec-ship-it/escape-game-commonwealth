🔒 Clause RGPD — Protection des données

⚠️ Clause en cours de rédaction — à compléter par l'établissement

Données collectées :
Cette application utilise un code anonyme (2 lettres du prénom + 2 lettres du nom + classe). Aucun prénom, aucun nom complet ni aucune donnée d'identification directe n'est enregistré.


Finalité :
Les données sont utilisées uniquement dans le cadre pédagogique, pour permettre au professeur de suivre la progression des élèves dans cette activité.


Stockage :
Les données sont stockées localement dans le navigateur de l'appareil utilisé (localStorage). Elles ne sont pas transmises à un serveur externe.


Droits :
Conformément au RGPD (Règlement Général sur la Protection des Données — UE 2016/679), vous disposez d'un droit d'accès, de rectification et d'effacement des données. Pour exercer ces droits, contactez l'établissement.
